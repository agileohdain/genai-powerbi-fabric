# Phase 2 — Ateliers sur les modèles réels du client

Application du module 02 sur un ou plusieurs rapports et modèles réels du client, publiés dans un espace de travail Copilot-enabled. Les ateliers se suivent : découverte et recette d'abord, capitalisation des prompts ensuite, adoption et diffusion enfin.

## Prérequis

- Copilot activé et vérifié (checklist de [docs/01-prerequis-activation](../../../docs/01-prerequis-activation/))
- Le(s) modèle(s) cible(s) audité(s) lors du [module 01](../../01-preparation-copilot-ready/phase2-ateliers/) et, idéalement, corrigés sur les points haute priorité (nommage, descriptions, champs visibles) : les ateliers 1 et 2 mesurent directement l'effet de cette préparation
- 2-3 utilisateurs métier disponibles pour formuler les vraies questions du quotidien (atelier 1) — ils sont les meilleurs auteurs de prompts

## Ateliers

| # | Atelier | Livrable | Durée indicative |
|---|---|---|---|
| 1 | [Découverte & recette](atelier-1-decouverte-recette.md) | Fiche de recette Copilot du rapport (vérification des réponses) | 0,5 jour |
| 2 | [Catalogue de prompts](atelier-2-catalogue-prompts.md) | Catalogue de prompts éprouvés par domaine métier | 0,25 jour |
| 3 | [Adoption & diffusion](atelier-3-adoption-diffusion.md) | Plan d'adoption : abonnements, découvrabilité, lignes de conduite | 0,25 jour |

## Conventions

- Chaque écart constaté (mauvaise réponse, champ mal choisi) est **documenté avec sa cause modèle** et alimente le plan d'action du module 01 — on corrige le modèle plutôt que le prompt quand c'est possible
- Rappel : les réponses sont non déterministes ; on valide une **plage de réponses acceptables**, pas un texte exact
