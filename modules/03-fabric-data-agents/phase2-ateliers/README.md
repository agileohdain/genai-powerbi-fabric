# Phase 2 — Ateliers d'application

Application sur les **modèles sémantiques réels du client** : construction d'un data agent pilote, recette de qualité, puis mise en place de la diffusion et de l'adoption. Le jeu AltiSport reste disponible comme terrain d'entraînement.

## Déroulé indicatif (≈ 0,75 jour)

| Horaire | Atelier | Objectif |
|---|---|---|
| 09h00 | [Atelier 1 — Construction & recette](atelier-1-construction-recette.md) | Spécifier et construire l'agent pilote sur un modèle réel, établir la recette de questions vérifiées (≈ 3 h 45) |
| 12h45 | Pause | — |
| 13h45 | [Atelier 2 — Diffusion & adoption](atelier-2-diffusion-adoption.md) | Publier, partager au groupe pilote, choisir les canaux, planifier itération et gouvernance (≈ 2 h 30) |

## Matériel requis

- Un modèle sémantique **réel préparé** (ou liste des écarts de préparation [module 01](../../01-preparation-copilot-ready/) si l'atelier sert d'abord à les révéler)
- Workspace sur capacité F2+ avec l'agent applicable ; droits suffisants pour créer des items et partager
- Un compte de test sans privilèges (valide le scénario « consommateur avec Read seul »)
