# Quiz — Module 01 · Préparation Copilot-ready

> À passer en fin de phase 1. 5 questions, ~10 min, sans notation : l'objectif est d'ancrer les acquis avant les ateliers. Les réponses sont pliées en bas de page.

## Questions

**1. La configuration *Prep data for AI* (schéma de données IA, réponses vérifiées, instructions IA) est stockée…**

- a) dans chaque rapport qui utilise le modèle
- b) au niveau du modèle sémantique — elle s'applique à tous les rapports
- c) dans les paramètres du tenant
- d) dans la capacité Fabric

**2. Pour être bien exploitées par l'IA, les descriptions de tables, colonnes et mesures doivent impérativement…**

- a) être rédigées intégralement, sans limite de longueur
- b) porter l'essentiel dans les 200 premiers caractères
- c) être rédigées en anglais uniquement
- d) être stockées dans un document markdown séparé

**3. Les instructions IA servent surtout à…**

- a) traduire le jargon métier interne pour Copilot (ex. « closers » = les vendeurs)
- b) remplacer les descriptions de tables et colonnes
- c) garantir une réponse identique à chaque question
- d) restreindre Copilot à certains utilisateurs

**4. Un modèle parfaitement préparé garantit-il que Copilot renvoie la même réponse à chaque fois ?**

- a) Oui — c'est l'objectif de la préparation
- b) Non — l'IA est non déterministe : la préparation améliore qualité et pertinence, sans garantir l'identité des réponses

**5. Dans la démarche officielle, la dernière étape avant de considérer le modèle prêt pour l'IA est…**

- a) rédiger les instructions IA
- b) renommer les tables et colonnes
- c) activer Q&A sur le modèle
- d) tester (skill picker, HCAAT) puis marquer le modèle *Approved for Copilot*

## Réponses

<details>
<summary>Corrigé — déplier après avoir répondu</summary>

**1. b** — Toute la configuration *Prep data for AI* vit dans le modèle sémantique, pas dans le rapport. → [fiche 02](02-schema-de-donnees-ia.md)

**2. b** — L'essentiel doit tenir dans les **200 premiers caractères** : c'est ce que l'IA lit en priorité. → [fiche 02](02-schema-de-donnees-ia.md)

**3. a** — Seule fonctionnalité qui transmet le vocabulaire interne : mapping, définitions conditionnelles, périodes métier. → [fiche 03](03-instructions-ia.md)

**4. b** — Non-déterminisme documenté : la préparation élève la qualité, pas la reproductibilité. → [fiche 01](01-evaluation-modele-semantique.md)

**5. d** — Tester rigoureusement puis valider *Approved for Copilot* est l'aboutissement de la démarche. → [fiche 04](04-approved-for-copilot.md)

</details>
