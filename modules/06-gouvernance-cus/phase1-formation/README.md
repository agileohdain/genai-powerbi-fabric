# Phase 1 — Formation & démonstrations

3 fiches (~2 h), démos sur la **capacité Fabric réelle** (celle ayant servi aux modules 02-03, pour avoir de l'usage IA à regarder) et la Metrics App.

| Fiche | Sujet | Démo | Durée indicative |
|---|---|---|---|
| [01 — Capacités & throttling](01-capacites-et-throttling.md) | CUs, F/P SKUs, bursting/smoothing, les 4 paliers, détection et remèdes | Lecture de la Metrics App : Utilization, Throttling, System events | ~40 min |
| [02 — Consommation des features IA](02-consommation-features-ia.md) | Tarifs par tokens, prompt caching, ordre de grandeur, MCP/Skills = 0 CU, pilote → extrapolation | Identifier Copilot in Fabric / AI Query et chiffrer un coût réel | ~40 min |
| [03 — Gouvernance & alertes](03-gouvernance-et-alertes.md) | Fabric Copilot capacity, alertes sur seuils, tenant settings, adoption incrémentale | Configurer une alerte sur seuil + décision FCC | ~40 min |

Prérequis : [setup/04](../../../setup/04-capacite-gouvernance.md) suivi (capacité identifiée, rôles, Metrics App) ; la référence [docs/04](../../../docs/04-consommation-cus-ia/) lue ou disponible ; historique d'usage IA sur la capacité (modules 02-03 déroulés).
