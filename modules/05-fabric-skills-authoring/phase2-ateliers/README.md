# Phase 2 — Ateliers d'application

2 ateliers sur les rapports réels du client (~0,75 jour). Pensés pour être animés en binôme formateur / équipe, avec la même recette que les fiches (validate → reload → screenshot).

| Atelier | Objectif | Livrable | Durée indicative |
|---|---|---|---|
| [Atelier 1 — Charte & refactoring](atelier-1-charte-refactoring.md) | Extraire la charte du client (PPT/maquettes), appliquer design brief + re-thémérisation, migrer les visuels legacy d'un rapport réel | Rapport re-thématisé et modernisé, basé sur la charte réelle | ~3 h |
| [Atelier 2 — Traduction & adoption](atelier-2-traduction-adoption.md) | Traduire un rapport réel en masse, exécuter la recette complète, décider de l'adoption de la démarche | Rapport traduit + bilan adopte/adapte/rejette | ~3 h |

Points clés communs : **baseline Git avant toute écriture**, revue humaine des propositions, et décision collégiale sur les types de rapports à intégrer au « flux skills ».

## Prérequis ateliers

- [setup/03](../../../setup/03-skills-copilot-cli.md) suivi sur les postes
- Accès au dépôt client (copy du template) avec les rapports réels en PBIP
- Desktop avec Desktop Bridge, compte avec capacité Fabric (voir [setup/01](../../../setup/01-powerbi-desktop.md))
- Charte/PowerPoint du client disponible en début d'atelier 1
