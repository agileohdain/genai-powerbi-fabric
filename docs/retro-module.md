# Rétro express de module

Modèle de rétro **5 minutes**, à passer en fin de chaque module (fin de phase 1 ou fin des ateliers). Format tour de table ou post-its anonymes — au choix du formateur.

## Les 3 questions

| # | Question | Ce que cela révèle |
|---|---|---|
| 1 | **Ce que je retiens** en une phrase | Les acquis qui ont marqué — à réutiliser en intro du module suivant |
| 2 | **Ce qui reste flou ou frustrant** | Les points à reprendre : rappel en début de session suivante, fiche à préciser |
| 3 | **Ce que j'applique dès demain** sur mes modèles/rapports | Le passage à la pratique — alimente le choix des cas d'atelier |

## Mode d'emploi du formateur

1. Réserver les 5 dernières minutes ; ne pas les sacrifier aux dépassements.
2. Noter les réponses brutes (une ligne par participant suffit).
3. Après la session : ouvrir **1 à 3 actions max** — un point flou repris vaut mieux que dix listés.
4. Ouvrir le module suivant par les « je retiens » de la rétro précédente : boucle de feedback visible pour l'équipe.

> La rétro de fin de formation (après le module 06) suit le même format : chaque participant partage ce qu'il applique en premier.

Modèle à copier :

```markdown
## Rétro — Module 0X · [date]

- Je retiens :
- Flou / frustrant :
- J'applique dès demain :

Actions formateur (max 3) :
1.
```
