# Doc 06 — Agenda suggéré

Deux déclinaisons du parcours (≈ 6,25 jours de contenu) : **intensif** et **alterné**. Les deux sont indicatifs — à ajuster selon la disponibilité des participants, l'état des modèles du client et les étapes admin ([docs/01](../01-prerequis-admin/)) qui doivent être faites **avant** le premier jour.

> Repères de durée : phase 1 ≈ 16 h de formation (M01-M02 ~3 h chacun, M03 ~3 h, M04-M05 ~2,5 h, M06 ~2 h) ; phase 2 ≈ 4,25 jours d'ateliers (M01-M05 ≈ 0,75 j chacun, M06 ≈ 0,5 j). Les durées détaillées figurent dans chaque module et chaque atelier.

## Format intensif — 7 jours ouvrés

Pour une équipe disponible et un objectif d'équipement rapide. Formation en bloc, puis ateliers enchaînés sur les modèles réels.

| Jour | Matin | Après-midi |
|---|---|---|
| **J1** | Formation M01 — préparation Copilot-ready | Formation M02 — Copilot Power BI |
| **J2** | Formation M03 — Fabric Data Agents | Formation M04 — MCP Data Modelling |
| **J3** | Formation M05 — Fabric Skills | Formation M06 — Gouvernance & CUs + quiz |
| **J4** | Ateliers M01 — audit & mise en œuvre/recette | (suite) |
| **J5** | Ateliers M02 — découverte/recette & prompts/adoption | (suite) |
| **J6** | Ateliers M03 — construction/recette & diffusion | (suite) |
| **J7** | Ateliers M04 puis M05 (profils dev) | Ateliers M06 + clôture : rétro globale 🏁 |

**Conseils** :
- J1 à J3 en présentiel de préférence (démos + questions) ; les quiz se passent en fin de J3.
- Les ateliers M04/M05 visent le même profil dev : ils peuvent s'enchaîner sur une journée et demie, ou se dérouler en parallèle par binômes.
- Garder la rétro express (5 min) en fin de chaque journée de formation ([modèle](../retro-module.md)).

## Format alterné — 7 semaines (1 journée / semaine)

Pour une équipe en production : une journée par semaine, le temps de digérer et d'appliquer entre deux sessions.

| Semaine | Journée | Contenu |
|---|---|---|
| **S1** | 1 j | Formation M01 + M02 |
| **S2** | 1 j | Formation M03 + M04 |
| **S3** | 1 j | Formation M05 + M06 + quiz |
| **S4** | ~0,75 j | Ateliers M01 — audit, mise en œuvre & recette |
| **S5** | 1 j | Ateliers M02 + lancement ateliers M03 |
| **S6** | 1 j | Fin ateliers M03 + ateliers M04 |
| **S7** | ~1 j | Ateliers M05 + M06, clôture : rétro globale 🏁 |

**Conseils** :
- L'alterné laisse 4 jours ouvrés entre sessions : les points durs remontés en rétro peuvent être traités avant la suivante.
- Espacer de **3-4 jours minimum** la formation d'un module et ses ateliers — les ateliers travaillent sur les modèles réels, pas sur des exercices.
- Si une semaine saute (congés, production), décaler tout d'un cran plutôt que de fusionner deux journées.

## Choix du format

| Critère | Intensif | Alterné |
|---|---|---|
| Disponibilité de l'équipe | Bloquée 2 semaines | 1 j/semaine soutenable |
| Maturité des modèles client | Peu importe (formation d'abord) | Idéal : corrections M01 intégrées avant ateliers M02+ |
| Effet d'entraînement | Fort (immersion) | Progressif (chacun applique entre deux) |
| Risque principal | Saturation en fin de parcours | Essoufflement, dépriorisation |

> Dans les deux cas : les ateliers produisent des **livrables réels** (plan d'action, recette, catalogue de prompts, charte de gouvernance) — c'est le retour sur investissement de la formation, à protéger dans les agendas.
