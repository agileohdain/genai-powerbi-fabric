# Passeport IA — suivi de progression

Votre suivi personnel à travers le parcours : **6 modules, 6 badges**. Conservez ce passeport tout au long de la formation (imprimé ou dupliqué dans votre espace) et cochez au fur et à mesure.

> **Comment obtenir un badge** : quiz d'ancrage ≥ 4/5 **et** ateliers du module réalisés avec leurs critères de succès remplis. Le badge se gagne sur preuve, pas sur présence.

---

## Étape 1 · 🛠️ Copilot-ready — [Module 01](../../modules/01-preparation-copilot-ready/)

**Je sais faire :**
- Évaluer et auditer un modèle sémantique au regard des exigences de l'IA
- Mettre en œuvre **Prep data for AI** : schéma de données IA, réponses vérifiées, instructions IA
- Tester rigoureusement (skill picker, HCAAT) puis valider avec *Approved for Copilot*

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/01-preparation-copilot-ready/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : grille d'audit complétée, plan d'action priorisé, modèle pilote mis en œuvre et recetté

**Badge obtenu le : ______**

## Étape 2 · 💬 Copilot — [Module 02](../../modules/02-copilot-powerbi/)

**Je sais faire :**
- Cartographier les expériences Copilot et choisir la bonne selon mon profil
- Créer et modifier des pages de rapport avec des prompts efficaces
- Poser des questions de données et **vérifier** les réponses (raisonnement, champs, filtres)
- Produire narratifs et résumés ; utiliser Copilot comme assistant de développement

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/02-copilot-powerbi/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : recette rejouable verdict par question, catalogue de prompts recettés et lignes de conduite publiées

**Badge obtenu le : ______**

## Étape 3 · 🤖 Fabric Agent — [Module 03](../../modules/03-fabric-data-agents/)

**Je sais faire :**
- Situer le data agent parmi les leviers IA et arbitrer (matrice d'arbitrage)
- Créer et configurer un agent : sources, tables, instructions, exemples
- **Évaluer et vérifier les réponses** : lire les requêtes générées, itérer
- Publier, partager et gouverner : versions, permissions, sécurité des sources

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/03-fabric-data-agents/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : agent pilote recetté (questions cadrées conformes), publié et partagé au groupe pilote avec note de gouvernance

**Badge obtenu le : ______**

## Étape 4 · 🔧 MCP — [Module 04](../../modules/04-mcp-data-modelling/)

**Je sais faire :**
- Expliquer MCP (client/serveur) et ce que le Power BI Modeling MCP Server sait faire
- Connecter l'environnement : VS Code, Copilot Chat, Desktop / Fabric / PBIP
- **Auditer un modèle** : analyse graduée, rapport, corrections avec confirmation
- **Documenter en masse** avec revue humaine ; appliquer les garde-fous (baseline Git, diff, lecture seule)

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/04-mcp-data-modelling/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : rapport d'audit committé + plan de correction priorisé ; modèle documenté (descriptions + markdown) et standard d'équipe adopté

**Badge obtenu le : ______**

## Étape 5 · 🎨 Fabric Skills — [Module 05](../../modules/05-fabric-skills-authoring/)

**Je sais faire :**
- Distinguer **skill** (instructions chargées à la demande) et **MCP** (outil)
- Installer l'environnement : Copilot CLI/VS Code, plugin `powerbi-authoring`, CLIs, Desktop Bridge
- Créer un rapport depuis un design brief avec charte visuelle
- Refactorer les visuels legacy, re-thémériser, traduire en masse — avec la boucle Edit → Validate → Reload → Screenshot

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/05-fabric-skills-authoring/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : charte appliquée + refactoring par lots validés ; traduction de masse avec décision d'adoption consignée

**Badge obtenu le : ______**

## Étape 6 · 🛡️ Gouvernance CUs — [Module 06](../../modules/06-gouvernance-cus/)

**Je sais faire :**
- Expliquer le modèle de capacité : CUs, F/P SKUs, bursting/smoothing, timepoints
- Reconnaître les **4 paliers de throttling** et savoir les lever
- Chiffrer la consommation IA (tarifs par tokens, prompt caching) et savoir **qui ne consomme rien** (MCP, Skills)
- Gouverner : Fabric Copilot capacity, alertes sur seuils, adoption incrémentale

- [ ] Quiz d'ancrage ≥ 4/5 → [quiz](../../modules/06-gouvernance-cus/phase1-formation/quiz.md)
- [ ] Ateliers 1-2 réalisés : capacité réelle mesurée (throttling détecté ou écarté) ; seuils d'alerte et plan de gouvernance actés

**Badge obtenu le : ______**
